# Codex App Plugin

The TDCanvas plugin connects Codex to a local TDCanvas Agent, allowing Codex to open the local canvas, read and create nodes, connect workflows, and start generation tasks. Its source is in `plugins/tdcanvas/`.

The plugin intentionally uses local source and a locally linked command. It does not depend on a remote npm package or a hosted TDCanvas site.

## Prepare TDCanvas Agent

Build TDCanvas Agent and register its local command once:

```bash
cd canvas-agent
npm install
npm run build
npm link
```

This makes the `tdcanvas-agent` command available to the plugin. Run `npm run build` again after changing TDCanvas Agent source.

## Ask Codex to install it

Open Codex in the TDCanvas source checkout and send this request:

```text
Install the local TDCanvas plugin from this source checkout. Build and link canvas-agent,
register the repository root as a local marketplace, install tdcanvas@tdcanvas-local,
validate the plugin and tell me whether a new conversation is required to load its Skill
and tdcanvas MCP tools.
```

## Manual installation

From the repository root on macOS or Linux:

```bash
codex plugin marketplace add "$(pwd)"
codex plugin add tdcanvas@tdcanvas-local
```

On Windows PowerShell:

```powershell
codex plugin marketplace add $PWD
codex plugin add tdcanvas@tdcanvas-local
```

The repository marketplace entry points to `./plugins/tdcanvas`. Start a new Codex conversation after installation so the Skill and MCP tools load completely.

## Usage

In a new Codex conversation, ask:

```text
Open TDCanvas, create a canvas, and connect Codex.
```

The plugin starts the local `web/` frontend and TDCanvas Agent, reads its connection URL and token, opens the local frontend, and creates and connects a canvas. You can then ask Codex to summarize the current canvas, create prompts from selected nodes, or organize nodes into a generation workflow.

## Update the plugin

Reinstall or refresh the plugin after changing any of these files:

- `plugins/tdcanvas/.codex-plugin/plugin.json`
- `plugins/tdcanvas/.mcp.json`
- Skills under `plugins/tdcanvas/skills/`
- Exposed MCP tools, app metadata, or entry scripts

Start a new Codex conversation after reinstalling to avoid using cached Skills and tools.

## Manual troubleshooting

The plugin starts TDCanvas Agent through this locally linked MCP command:

```bash
tdcanvas-agent mcp
```

To run the components separately, start the frontend from the repository root:

```bash
cd web
npm install
npm run dev
```

Then start TDCanvas Agent in another terminal:

```bash
cd canvas-agent
npm install
npm run build
node dist/index.js
```

Read `Local URL` and `Connect token` from the TDCanvas Agent output or `http://127.0.0.1:17371/config`, then open:

```text
http://localhost:3000/canvas?mode=new&agentUrl=<Local URL>&agentToken=<Connect token>
```

`mode=new` creates a canvas and connects it to the local TDCanvas Agent automatically.
