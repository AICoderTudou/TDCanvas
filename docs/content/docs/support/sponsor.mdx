# Sponsor the Project

You can support TDCanvas by starring the repository, contributing fixes or documentation, sponsoring project placement, or providing subscriptions to AI development tools such as Codex or Claude. Support is used for AI development tools, model services, and project maintenance.

No public sponsorship address is currently published. Use only an official sponsorship or private maintainer channel configured for the repository. Include the brand or product, desired placement and duration, link and creative materials, budget, and preferred cooperation model.

Relevant sponsors include AI tools, model and API services, developer tools, creation workflows, and services useful to open-source users and AI creators.
